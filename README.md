# استوديو الأبحاث — RGBOO Research Studio — ✦ RGBOO ✦

**البحث الأكاديمي المحترم مش لازم ياخد أسبوع... أحيانًا بياخد جلسة واحدة منظمة.**

تطبيق عربي مجاني بيكتب معك البحث الأكاديمي كاملاً من الغلاف للمراجع: بيانات وخطة أولاً، ثم توليد قسماً قسماً بمحركات ذكاء اصطناعي مجانية أو بمفتاحك الخاص، وصور موثّقة الصلة بالمحتوى، وتصدير احترافي جاهز للطباعة والتسليم.

## التحميل

**[⬇ تحميل أحدث إصدار (APK لأندرويد)](https://github.com/rgboo/rgboo-research/releases/latest/download/RGBOO-Research-Studio.apk)**

- الإصدار الحالي: 1.32
- يعمل على أندرويد 7.0 فأحدث، وحجمه أقل من ربع ميجا.
- التطبيق يحدّث نفسه: أي إصدار جديد هيظهر لك من جوه التطبيق بزر «حدّث الآن».

## بيعمل إيه؟

- **ثلاث خطوات وبس:** ١ بيانات البحث والطالب ← ٢ الخطة والمحرك ← ٣ الاستوديو. الخطة وعناوين الفصول بتتولّد الأول وبتتعدّل قبل كتابة أي كلمة.
- **توليد قسماً قسماً بمحركات حقيقية:** مجاناً بلا أي مفتاح (سلسلة محركات مجانية باحتياطي تلقائي)، أو بمفتاحك الخاص من ١١ موفّراً عالمياً (Groq وGemini وOpenRouter وOpenAI وClaude وغيرها).
- **«توليد الناقص»:** لو أي قسم فشل أو ناقص، الزر — ولونه بيعبّر عن حالته وعدّاده شغال — بيكتب الناقص بس، من غير ما يعيد البحث كله.
- **صور ببوابة صلة:** كل شكل بيتختار بصلة موثّقة بعنوان البحث وقسمه من ويكيبيديا العربية وويكيميديا والمصادر المفتوحة، وتسميته هي وصفه الحقيقي — ومفيش صورة واثقة الصلة = مفيش شكل أصلاً. ومن درج أي قسم تقدر تحذف أو تستبدل أي شكل بنفسك.
- **غلاف وتصدير احترافي:** غلاف مصمم بكتلة بيانات الطالب، إطار اختياري للصفحات، ترقيم صفحات بأرقام عربية، وفهرس تلقائي — و**ثلاث طرق PDF مستقلة** (طباعة أصلية + محركان برمجيان)، ومعاهم Word وHTML وLaTeX وMarkdown ونص خام ونسخة احتياطية JSON.
- **المنظّم الذكي:** بيراجع البحث كله وينضّفه ويرتّبه قبل التصدير، مع فحص جودة قبل التسليم.
- **ملء تلقائي لبيانات الطالب:** بيتعلّم من كتابتك وبيملأ البيانات المتكررة عند تطابقها — وبيتمسح من الإعدادات وقت ما تحب.
- **مكتبة «أبحاثي» وقوالب:** احفظ أبحاثك وارجع لها في أي وقت، وابدأ من قوالب جاهزة لأنواع الأبحاث الشائعة.

## صدق قبل كل شيء

- **البحث يخرج باسمك وحدك:** صفر أثر لاسم البرنامج داخل أي مستند مُصدَّر — لا شعار ولا توقيع ولا اسم أداة، لا في الصفحات ولا في بيانات الملف، وعنوان ملف الـPDF هو عنوان بحثك نفسه.
- **مفاتيحك على جهازك بس:** مفيش أي مفتاح API مدمج في التطبيق إطلاقاً؛ مفاتيح الموفرين بتتحفظ في متصفح جهازك ولا تغادره إلا لموفّرها نفسه.
- **الأخطاء بتتقال بصراحة:** أي فشل بيظهر سببه بعربي مفهوم — والنص التقني محفوظ في تقرير الخطأ المنسوخ بس — ومعاه زر «جرّب الطريقة التانية» بينفّذ البديل بلمسة واحدة. مفيش نجاح وهمي: الشريط الأخضر لا يظهر إلا لما كل الأقسام تكون مكتوبة فعلاً.
